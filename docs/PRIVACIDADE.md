# Política de Privacidade — SlandBar

_Última atualização: 9 de agosto de 2026_

## Resumo

**A SlandBar não coleta, não armazena e não compartilha nenhum dado pessoal.** Todo o funcionamento do aplicativo é 100% local no seu aparelho. Não existem servidores, não existem contas e não existem anúncios com rastreamento.

## 1. Dados que o aplicativo acessa

| Dado | Uso | Envio para fora do aparelho |
|---|---|---|
| Sessões de mídia ativas (título/artista da música tocando) | Exibir e controlar o widget de música | **Nunca** |
| Estado do flash, brilho, volume, modo de som | Executar os atalhos que você pediu | **Nunca** |
| Lista de aplicativos instalados | Mostrar a lista para você escolher atalhos | **Nunca** |
| Capturas de tela | Somente quando **você** aciona o atalho "Captura"; a imagem fica salva na sua galeria | **Nunca** |
| Configurações do app (atalhos, tamanho, tema) | Salvas localmente no aparelho (DataStore) | **Nunca** |

## 2. Serviço de acessibilidade

A SlandBar usa o Android Accessibility Service **exclusivamente** para:

1. Tirar capturas de tela quando você aciona o atalho correspondente;
2. Abrir o menu de energia e a sombra de notificações;
3. Recolher a barra flutuante quando o teclado está aberto.

O serviço **não lê** conteúdo de telas, textos digitados, senhas ou dados de outros aplicativos, e **não envia nada** para nenhum lugar.

## 3. Permissões

Cada permissão tem um uso específico e é solicitada somente quando o recurso é usado: sobreposição de tela (a barra flutuante), câmera (apenas o flash), modificação de configurações (brilho), notificações (manter o serviço ativo), política de notificações (modo "Não perturbe") e vibração (feedback dos gestos).

## 4. Compras

O Premium é uma compra processada integralmente pelo Google Play. A SlandBar recebe apenas a confirmação de que a compra ocorreu — nenhum dado de pagamento passa pelo aplicativo.

## 5. Crianças

O aplicativo é adequado para todas as idades (classificação "Todos") e não coleta dados de nenhum usuário, incluindo crianças.
